# Código de Conduta

## O nosso compromisso

Queremos que participar neste projeto seja uma experiência respeitosa e sem assédio para todas as pessoas, independentemente de idade, género, origem, língua, aparência, deficiência, orientação, religião ou experiência.

## O que esperamos

* Tratar os outros com respeito e paciência, sobretudo a quem está a começar.
* Criticar o código e as ideias, nunca as pessoas.
* Aceitar bem a crítica e dar o crédito a quem o merece.
* Pôr o interesse de quem usa o projeto à frente do nosso gosto.

## O que não toleramos

* Insultos, ataques pessoais, assédio, discriminação.
* Divulgar dados pessoais de terceiros sem autorização.
* Spam e publicidade sem relação com o projeto.

## Aplicação

Os mantenedores podem editar ou remover comentários, issues e *pull requests* que fujam a este código, e afastar quem o infrinja repetidamente. Para reportar uma situação, escreva para **geral@codespace.ao**; a identidade de quem reporta é tratada com confidencialidade.

Este código adapta o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/), versão 2.1.
